# Automated Road Damage Detection Using UAV Images and Deep Learning Techniques

## Project Overview

This project focuses on detecting road damage using Unmanned Aerial Vehicle (UAV) images and deep learning techniques.

The application provides a graphical user interface for working with road images and displaying road damage detection results. The project explores different YOLO-based object detection approaches for identifying road damage.

## Objectives

- Detect road damage from road images.
- Explore deep learning techniques for automated road damage detection.
- Use UAV images and publicly available road damage datasets.
- Provide a graphical interface to interact with the detection application.
- Examine model predictions and detection performance.

## Technologies Used

- Python 3.7
- Deep Learning
- YOLO
- OpenCV
- TensorFlow / Keras
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Tkinter

## Dataset

The project uses road image data from the following sources:

- UAV road images
- RDD2022 China Drone dataset
- Spanish road dataset

## Installation and Execution

### Prerequisites

- Windows operating system
- Python 3.7
- Required Python libraries

### Step 1: Clone the repository

```bash
git clone https://github.com/nasr5368717-crypto/Automated-Road-Damage-Detection.git
```

### Step 2: Open the project folder

```bash
cd Automated-Road-Damage-Detection
```

### Step 3: Install dependencies

```bash
py -3.7 -m pip install -r requirements.txt
```

### Step 4: Run the application

```bash
py -3.7 Main.py
```

Alternatively, Windows users can launch the application using the provided `run.bat` file.

**Note:** The application may require additional dataset or model files at the paths expected by the source code. Make sure these files are available before running it.
